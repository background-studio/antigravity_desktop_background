# Antigravity Background Studio v0.1.2

修复打开内置浏览器侧栏时中间会话主区域变黑的问题，并提升浏览器挖洞区域裁切的精准度与拖拽跟随响应。

## 修复与改进

- **修复打开内置浏览器侧栏后主画布变黑**：当内置浏览器侧栏展开并触发 `body[data-has-browser-hole="true"]` 时，Antigravity 原生样式会通过 `.browser-hole-opaque`、`[data-pane-id]`、`[data-split-sash]` 与分屏节点直接引用 `var(--background)` 回填实色背景。现于 `#root` 作用域内补充 `--background: transparent !important;`（绝不改动 `:root` 原版变量，确保 `app_storage.json` 与主题自动同步不受影响），同时继续保护反色文字与浮层弹框可读性。
- **内置浏览器视口精确避让**：`[data-side-panel-body="true"][data-has-browser-hole="true"]` 与 `[data-browser-hole]` 不再叠加半透明底色；背景层 `clip-path` 改为优先匹配精确的 `[data-browser-hole]` 视口节点，并通过 `ResizeObserver` 与拖拽/过渡监听实时更新挖洞坐标。

## 验证情况

- 已在 Windows Antigravity Desktop 2.35.2 真实展开右侧内置浏览器侧栏（`body[data-has-browser-hole="true"]`）时实时验证并截图复核：左侧边栏、顶部栏、中间会话主区与浏览器标签栏均平滑透出自定义背景，右侧内置浏览器视口无黑遮罩且清晰可交互。
- 已通过 `cargo fmt --all -- --check`、`cargo test --locked`、`cargo build --locked --release`。
