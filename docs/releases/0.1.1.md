# Antigravity Background Studio v0.1.1

修复会话窗口中 Markdown 代码块外层的直角黑框与高不透明底色，并统一构建期脚本换行符规范。

## 修复与改进

- **会话代码块样式修复**：Antigravity 的 Markdown 代码块由透明 `<pre class="notranslate">` 包裹内层 `rounded-xl` 圆角卡片（含语言标题与复制按钮）。此前规则直接给 `<pre>` 刷了终端不透明度底色，导致圆角卡片上下露出直角黑框且整体偏暗不透明；现改为外层 `<pre>` 透明、内层圆角卡片按「卡片不透明度」单层着色，与消息气泡、输入框视觉一致。
- **构建与 CI 稳定性**：`build.rs` 读取 `src/main/payload.ts` 时统一将 `\r\n` 规范为 `\n`，消除 Windows CI 检出换行符差异导致的单测失败与修订号不一致。

## 验证情况

- 已在 Windows Antigravity Desktop 2.35.2 真实会话页面的 `bash` 代码块上实时验证：外层 `<pre>` 背景透明、无直角黑框，内层圆角代码卡片按 `cardOpacity` 单层半透明呈现，代码高亮与复制按钮清晰可读。
- 已通过 `cargo fmt --all -- --check`、`cargo test --locked`、`cargo build --locked --release` 与图标校验。
