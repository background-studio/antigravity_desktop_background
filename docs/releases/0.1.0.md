# Antigravity Background Studio v0.1.0

首个正式版本，为 Windows 桌面版 Antigravity（Electron 44 / Hub UI）提供无侵入背景图与视频支持。

## 主要特性

- **协议 2 纯 Rust 无界面 worker**：仅通过本机回环 CDP 注入 Hub 渲染页，不修改 `Antigravity.exe`、`app.asar` 或任何安装文件，与代理补丁、汉化补丁零冲突。
- **图片与视频支持**：最高 64 MB，通过 192 KB 分块 Blob 上传绕过 CSP 且不落盘。
- **多窗口独立背景（`perWindowMedia: true`）**：支持 Background Studio 壳为每个 Antigravity 窗口独立分配与轮播背景。
- **Antigravity 专属分层样式适配**：
  - 不修改 `:root` 上的原版 `--background` 等变量，避免污染 `app_storage.json`，并实时跟随深色/浅色主题。
  - 顶栏、侧栏、主画布、右侧辅助面板与毛玻璃输入区各自单层着色，清除会话页底部渐隐黑带，保护反色按钮与弹层可读性。
  - 内置浏览器展开挖洞（`data-has-browser-hole="true"`）时自动以 `clip-path` 抠洞避让。
- **稳健进程托管**：纯 Win32 API 进程追踪与重启，自动跳过 `ELECTRON_RUN_AS_NODE` 的 `sidecar_sdk` 进程；`shutdown` 时保留目标程序与已注入背景，支持通过 `runtime.json` 零重启重连。

## 验证情况

- 已在 Windows Antigravity Desktop 2.35.1 上完成图片（主页/会话页/设置弹层）、浅色主题模拟、WebM 视频播放、内置浏览器挖洞避让、页面重载恢复、`shutdown` 保背景 + 重连、`pause` 与 `restore` 真机验证。
- 多窗口独立背景的协议单测与定向窗口配置已通过，多窗口同时打开时的轮播效果请在壳内按 `Ctrl+Shift+N` 实际体验反馈。
